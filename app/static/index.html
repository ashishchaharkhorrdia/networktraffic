                        System Privileges & Operational Modes
                    

                    
CyberNinjas executes in two operating modes depending on
                        system kernel capabilities.

                


                

                    
                    

                        

                            
                            1. Standard User Mode (Active)
                        

                        

                            Executes without root or sudo privileges. Collects real-time interface throughput,
                            upload/download metrics, active socket connections, process attribution, subnet discovery,
                            firewall blocklists, and PCAP file analysis.
                        

                    


                    
                    

                        

                            
                            2. Kernel Raw Socket Mode (Optional)
                        

                        

                            Enables raw promiscuous packet capture via kernel AF_PACKET sockets. Requires either running
                            with administrative privileges or granting the Python binary specific Linux capabilities.
                        

                    

                


                
                

                    
                    

                        sudo setcap cap_net_raw,cap_net_admin=eip $(which python3)
                        
                    

                    
This grants the Python runtime packet capture capabilities without
                        requiring full root execution.
